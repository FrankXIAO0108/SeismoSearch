# Earthquake Catalog Fields

## 文档目的

本文档解释 SeismoSearch 结构化地震事件库中的核心字段含义。

这些字段主要用于支持历史地震事件查询、震级过滤、时间排序、深度统计和事件证据生成。

本文档不用于预测未来地震。

---

## Event ID

Event ID 是地震事件在数据源中的唯一标识。

在 SeismoSearch 中，event_id 用于：

- 标识一条地震事件；
- 支持事件证据追踪；
- 避免不同事件在回答中混淆；
- 在 Evidence Pack 中引用具体事件。

Event ID 本身不表示地震强弱，也不表示风险等级。

---

## Time

Time 表示地震事件发生的时间。

在 SeismoSearch 中，time 字段用于：

- 按时间范围过滤事件；
- 查询最近或最新事件；
- 按时间倒序排列事件；
- 支持用户问题中的年份、月份、最近等时间表达。

# Interpreting Changes in Earthquake Counts

## Short-term Fluctuation

一段时间内地震数量增加或减少，可能只是正常的随机波动。仅凭全球或某地区“最近地震很多”，不能推出一场更大地震即将发生；事件数量变化需要结合目录完整性、震级阈值、监测能力和空间范围解释。

## Catalog Completeness Changes

现代地震目录记录的事件更多，不一定表示真实地震活动整体增加。台站数量、仪器灵敏度、通信能力和自动处理系统的提升，会让更多小事件被发现并进入目录。

## Comparable Counting

比较不同时段时必须保持相同的数据源、空间范围、震级阈值、事件类型和时间长度。否则观测到的差异可能来自查询口径，而不是地震活动本身。

## Historical Statistics Boundary

历史统计可以描述目录中已经发生的事件，例如每年 M7 以上事件数，但不能单独提供未来具体事件预测。长期平均值也不意味着每一年都接近平均值。

# Magnitude and Shaking Intensity

## Magnitude Describes the Source

震级描述地震源的规模。一个事件通常有一个主要震级估计，但不同机构、震级算法和数据更新可能产生略有差异的数值。震级不随观察地点改变。

## Intensity Describes Local Effects

烈度描述某个地点的震动或可观察影响，因此同一地震可以在不同地点产生不同烈度。距离断层的远近、震源深度、破裂方向、局地地质和建筑条件都会影响当地表现。

## Modified Mercalli Intensity

Modified Mercalli Intensity 使用罗马数字表示不同等级，依据人员感受、物体反应和建筑损伤等可观察信息。它与基于地震仪记录计算的震级不是同一量。

## Impact Is Not Determined by Magnitude Alone

相同震级的两场地震可能造成不同影响。回答影响问题时至少需要考虑距离、深度、人口暴露、场地放大、建筑脆弱性和次生灾害；不能只根据 magnitude 排序推断损失。

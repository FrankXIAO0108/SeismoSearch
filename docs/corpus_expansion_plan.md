# SeismoSearch 领域知识库扩展方案

## 1. 阶段目标

本阶段的目标，是将 SeismoSearch 当前的小规模领域文档集合，扩展为一个来源可追溯、主题覆盖明确、能够支持独立评测的地震领域 RAG corpus。

本阶段不追求盲目增加文档数量，也不以“文档越多越好”为目标，而是围绕 SeismoSearch 的真实用户任务建立知识覆盖矩阵。

目标用户主要包括：

- 使用 USGS 公开目录进行基础数据分析的地学学生；
- 需要理解 USGS 事件字段的公开数据分析者；
- 需要进行地震科普与科学风险沟通的内容工作者；
- 需要查询历史地震事件并理解相关概念的普通用户。

目标工作流包括：

```text
理解用户问题
-> 判断结构化查询、知识解释或安全问题
-> 查询 DuckDB 事件库
-> 检索权威领域文档
-> 构建 Evidence Pack
-> 基于证据生成回答
